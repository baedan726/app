Swiper.js
3

debounce 패턴

테마 태그 → 검색 결과 이동

👣 사용자 시나리오
1
전체 예약 로딩 + 스켈레톤 UI
onMounted에서 GET /api/my/reservations(위경도 포함)를 호출해 Pinia reservationStore에 저장. 로딩 중 스켈레톤 카드 3개 표시.
2
상태 탭 — computed 로컬 필터
탭 클릭 시 API 재호출 없이 Pinia computed가 목록을 상태별 분류. 탭 배지에 건수 실시간 표시.
Pinia computed
3
카드 클릭 → 상세 모달 + 카카오 미니맵
예약번호·일정·금액·상태와 카카오맵 미니맵(300×200px)으로 여행지 위치 시각화. 길찾기 버튼 제공.
Kakao 미니맵
4
취소 → 환불 정책 모달
GET cancel-policy로 환불 금액 계산 후 모달 표시. 확인 시 PATCH cancel로 DB 상태변경 + PG 환불 + 이메일 처리.
5
이용완료 → 리뷰 작성 인라인 폼
statusCode=COMPLETED && reviewWritten=false 조건 시 버튼 표시. 인라인 폼으로 별점+텍스트 입력 → POST /api/review.
