👣 관리자 시나리오 — 배너 등록 플로우
1
배너 등록 수 제한 체크 (최대 10개)
현재 등록 수가 10개에 도달하면 "새 배너 등록" 버튼이 비활성화됩니다. 상단 카운터 7/10으로 현황을 한눈에 확인. 종료된 배너를 삭제하면 슬롯이 복구돼요.
최대 10개 제한
2
이미지 + 링크 + 날짜 설정
이미지(최대 5MB, 1920×600px)를 업로드하고 클릭 시 이동할 링크 URL, 노출 시작/종료일을 설정합니다. 종료일을 비워두면 무기한 노출이에요.
3
저장 → @CacheEvict → 사용자 즉시 반영
POST /admin/main-content 저장 시 @CacheEvict("mainContent")가 실행되어 캐시가 즉시 무효화됩니다. 다음 사용자 접속부터 새 배너가 메인 홈에 자동 표시돼요!
@CacheEvict
4
순서 드래그&드롭 → 일괄 저장
배너 목록의 ⠿ 핸들을 드래그해 순서를 변경하고 "순서 저장" 버튼 클릭 시 PATCH /admin/main-content/reorder로 SORT_ORDER를 일괄 업데이트합니다.
5
노출 기간 만료 → @Scheduled 자동 비활성화
매일 자정 @Scheduled가 TB_MAIN_CONTENT를 스캔해 END_DT ≤ 현재시간인 항목의 USE_YN = 'N'으로 자동 업데이트. 수동 종료 불필요!
