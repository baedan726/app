JDK 17 설치 및 환경변수 설정 필수
▼

전자정부 5.0은 Java 17 이상을 권장합니다.

① 다운로드

  2. Temurin 17 (LTS) → Windows x64 → .msi 다운로드

⚠️
설치 중 "Set JAVA_HOME variable" 항목이 나오면 반드시 Will be installed on local hard drive로 변경하세요.
② 설치 확인 (CMD 새로 열기)
cmd
java -version

정상 출력 예시:

출력 예시

OpenJDK Runtime Environment Temurin-17.0.10+7
③ 환경변수 수동 설정 (자동 설정 안 된 경우)
  1. Windows 검색 → "시스템 환경 변수 편집" → 환경 변수 버튼
  2. 시스템 변수 → 새로 만들기
  3. 변수 이름: JAVA_HOME / 변수 값: C:\Program Files\Eclipse Adoptium\jdk-17.x.x.x-hotspot

MySQL 연동 설정 (pom.xml + properties + MyBatis)
▼

기본 프로젝트는 HSQLDB(내장 DB)를 사용합니다. 이를 MySQL로 교체합니다.

① pom.xml — MySQL 드라이버 추가

    <groupId>com.mysql</groupId>
    <artifactId>mysql-connector-j</artifactId>
    <version>8.3.0</version>
</dependency>
<!-- 기존 HSQLDB 주석 처리 -->

저장 후 → 프로젝트 우클릭 → Maven → Update Project → OK

② globals.properties — DB 접속 정보
globals.properties
Globals.DbType = mysql
Globals.DriverClassName = com.mysql.cj.jdbc.Driver
Globals.Url = jdbc:mysql://localhost:3306/teamdb?useSSL=false&serverTimezone=Asia/Seoul&characterEncoding=UTF-8&allowPublicKeyRetrieval=true
Globals.UserName = team_user
Globals.Password = team1234
③ MyBatis XML 매퍼 예시 (CRUD)
MemberMapper.xml
<mapper namespace="memberMapper">
    <!-- 전체 목록 조회 -->
    <select id="selectMemberList" resultType="MemberVO">
        SELECT * FROM member ORDER BY member_id DESC
    </select>
    <!-- 단건 조회 -->
    <select id="selectMember" parameterType="int" resultType="MemberVO">
        SELECT * FROM member WHERE member_id = #{memberId}
    </select>
    <!-- 등록 -->
    <insert id="insertMember" parameterType="MemberVO">
        INSERT INTO member (username, password, email)
        VALUES (#{username}, #{password}, #{email})
    </insert>
    <!-- 수정 -->
    <update id="updateMember" parameterType="MemberVO">
        UPDATE member SET email=#{email} WHERE member_id=#{memberId}
    </update>
    <!-- 삭제 -->
    <delete id="deleteMember" parameterType="int">
        DELETE FROM member WHERE member_id = #{memberId}
    </delete>
</mapper>
④ Controller → Service → DAO 3계층 예시
MemberController.java
@Controller
@RequestMapping("/member")
public class MemberController {
    @Autowired private MemberService memberService;

    @RequestMapping("/list.do")
    public String list(Model model) throws Exception {
        model.addAttribute("memberList", memberService.selectMemberList());
        return "member/memberList"; // WEB-INF/jsp/member/memberList.jsp
    }
}
MemberDAO.java
@Repository("memberDAO")
public class MemberDAO extends EgovAbstractMapper {
    public List<MemberVO> selectMemberList() {
        return selectList("memberMapper.selectMemberList");
    }
    public void insertMember(MemberVO vo) {
        insert("memberMapper.insertMember", vo);
    }
}

Vue 컴포넌트 기본 작성법 (Composition API)
▼

Vue 3의 Composition API (script setup) 방식입니다. 간결하고 TypeScript 친화적이라 권장합니다.

MemberList.vue — 기본 예시
<template>
  <div>
    <h2>{{ title }}</h2>

    <!-- v-for: 배열 반복 출력 -->
    <ul>
      <li v-for="member in members" :key="member.id">
        {{ member.username }} — {{ member.email }}
      </li>
    </ul>

    <!-- v-model: 입력값 양방향 바인딩 -->
    <input v-model="searchText" placeholder="검색어 입력" />
    <p>검색어: {{ searchText }}</p>

    <!-- @click: 클릭 이벤트 -->
    <button @click="loadMembers">목록 불러오기</button>
  </div>
</template>

<script setup>
import { ref, onMounted } from 'vue'
import api from '@/utils/api'

const title = '회원 목록'
const members = ref([])      // 반응형 배열
const searchText = ref('')  // 반응형 문자열

onMounted(() => { loadMembers() })  // 마운트 시 자동 실행

async function loadMembers() {
  const res = await api.get('/member/list')
  members.value = res.data
}
</script>

<style scoped>
/* scoped: 이 컴포넌트에만 적용 */
button { padding: 8px 16px; background: #4f8ef7; color: white; border: none; border-radius: 4px; }
</style>

백엔드 REST Controller
MemberApiController.java
@RestController
@RequestMapping("/api/member")
public class MemberApiController {
    @Autowired private MemberService memberService;

    @GetMapping("/list")
    public ResponseEntity<List<MemberVO>> list() throws Exception {
        return ResponseEntity.ok(memberService.selectMemberList());
    }
    @PostMapping("/insert")
    public ResponseEntity<String> insert(@RequestBody MemberVO vo) throws Exception {
        memberService.insertMember(vo);
        return ResponseEntity.ok("success");
    }
}
